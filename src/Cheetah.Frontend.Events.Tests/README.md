# Cheetah.Frontend.Events.Tests

Unit тесты для модуля Cheetah.Frontend.Events.

## Структура тестов

### CrmInMemoryEventBusTests
Unit тесты для CrmInMemoryEventBus:
- Тестирование публикации одного события
- Тестирование публикации множественных событий
- Тестирование подписки на события
- Тестирование вызова хэндлеров при публикации событий
- Тестирование множественных хэндлеров для одного события
- Тестирование обработки ошибок в хэндлерах
- Тестирование создания DI scope для хэндлеров
- Всего: **8 тестов**

## Запуск тестов

```bash
# Запустить все тесты
dotnet test

# Запустить с подробным выводом
dotnet test --logger "console;verbosity=normal"
```

## Покрытие кода

Все основные сценарии работы с In-Memory Event Bus покрыты тестами:
- ✅ Публикация событий (одно и множественные)
- ✅ Подписка на события
- ✅ Вызов хэндлеров
- ✅ Множественные хэндлеры для одного события
- ✅ Обработка ошибок в хэндлерах
- ✅ Создание DI scope для обработчиков
- ✅ Отсутствие подписчиков

## Используемые библиотеки

- **xUnit** - фреймворк для тестирования
- **FluentAssertions** - библиотека для читаемых assertions
- **Microsoft.Extensions.DependencyInjection** - для DI scope

## Архитектура тестов

Тесты НЕ используют моки, а тестируют реальную реализацию `CrmInMemoryEventBus` с реальным DI контейнером. Это позволяет:
- Тестировать интеграцию с DI контейнером
- Проверять создание scope'ов
- Убедиться, что обработчики действительно вызываются
