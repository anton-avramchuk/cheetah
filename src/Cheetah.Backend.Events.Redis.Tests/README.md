# Cheetah.Backend.Events.Redis.Tests

Unit тесты для модуля Cheetah.Backend.Events.Redis.

## Структура тестов

### CrmRedisEventBusTests
Unit тесты для CrmRedisEventBus с использованием моков:
- Тестирование публикации одного события
- Тестирование публикации множественных событий
- Тестирование подписки на события
- Тестирование вызова хэндлеров при получении событий
- Тестирование множественных хэндлеров для одного события
- Тестирование обработки ошибок в хэндлерах
- Всего: **8 тестов**

## Запуск тестов

```bash
# Запустить все тесты
dotnet test

# Запустить с подробным выводом
dotnet test --logger "console;verbosity=normal"
```

## Покрытие кода

Все основные сценарии работы с Event Bus покрыты тестами:
- ✅ Публикация событий (одно и множественные)
- ✅ Подписка на события
- ✅ Вызов хэндлеров
- ✅ Множественные хэндлеры для одного события
- ✅ Обработка ошибок в хэндлерах
- ✅ Использование настроек (InstanceName, ChannelPrefix)

## Используемые библиотеки

- **xUnit** - фреймворк для тестирования
- **FluentAssertions** - библиотека для читаемых assertions
- **Moq** - библиотека для создания моков
- **Microsoft.Extensions.Options** - для конфигурации
- **Microsoft.Extensions.DependencyInjection** - для DI scope

## Архитектура тестов

Тесты используют моки для:
- `IRedisEventBus` - низкоуровневая работа с Redis
- `IServiceProvider` - DI контейнер
- `IServiceScope` - DI scope для хэндлеров
- Хэндлеры событий

Это позволяет тестировать логику Event Bus изолированно от Redis и DI контейнера.
